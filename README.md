# Gout Clinical Management Protocol (gout-management-protocol) v1.0.0

서울대병원 류마티스내과 이은봉 교수 강의 기반 통풍(Gout) 병태생리, 급성기 통증 진압, 만성기 요산 관리, 식단 및 생활습관 전담 임상 의사결정 지원 스킬.

## 핵심 임상 철학 (5대 원칙)
1. 유전-대사 결합 질환 규정 (요산분해효소 Uricase 결손 + 신장 배설저하 유전)
2. 조기 약물 평생 관리 (식이제한만으로는 1~2 mg/dL 강하 불과, 연 2회 이상 발작 시 XOI 매일 복용)
3. 엄격한 요산 목표치 (일반 통풍 < 6.0 mg/dL, 결절성 통풍 < 5.0 mg/dL)
4. 급성기 vs 만성기 분리 (급성기 소염진통제 집중, 요산저하제 신규투여 절대금기)
5. 요산 급변동(Rapid Fluctuation) 차단 (급상승 및 급강하 모두 발작 유발)

## 생화학적 위험 요인 및 식단
- 알코올: 젖산(Lactate)의 신장 요산 배설 억제, 맥주 효모 퓨린
- 과당: 간 내 ATP 급격 고갈에 따른 퓨린 대사 폭증
- 체중 감량 제1원칙: 총 칼로리 감소가 단순 퓨린 제한보다 훨씬 중요
- 식물성 퓨린 안심: 콩, 두부, 버섯, 시금치 제한 불필요
